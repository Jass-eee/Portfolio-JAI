# Deploy this portfolio to Vercel

This package is a production-ready Next.js portfolio and does not require environment variables.

## Recommended: deploy with GitHub

1. Extract this ZIP.
2. Create a new GitHub repository and upload the extracted files.
3. In Vercel, choose **Add New → Project** and import that repository.
4. Keep the detected framework as **Next.js** and click **Deploy**.

## Deploy with the Vercel CLI

1. Extract this ZIP and open the extracted folder in a terminal.
2. Run `npm install`.
3. Run `npx vercel` and follow the prompts.
4. Run `npx vercel --prod` when you are ready to publish the production URL.

Vercel should use `npm run build` automatically. The portfolio has already been verified with a production build.
